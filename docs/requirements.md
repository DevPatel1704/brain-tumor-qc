Status values: **verified** (a test that runs in CI passes), **implemented, not run on real data** (code and fixture tests exist, but the real-data check needs more training), **pilot** (measured on the 2026-11-13 laptop run: one held-out fold, 10 epochs, sampled test cases), **not run**.

## How the matrix is kept honest
- Every "verified" row names a test that runs in `make test` or `make test-ui` on synthetic fixtures only, so it passes in CI without data or a GPU.
- Rows that need more training (other folds, methods, seeds) say "not run"; pilot measurements say "pilot". The scripts that produce those numbers exist (`scripts/e1_gap.py` ... `scripts/e6_software.py`) and write a "not run" record with the reason when their inputs are missing.
