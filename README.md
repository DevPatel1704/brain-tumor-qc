# btqc: uncertainty-gated brain tumor segmentation across hospitals

> **Research prototype only. Not a medical device and not for diagnosis.**
> The trust flag is advisory and depends only on an uncertainty score and a configurable review limit.

btqc extends **nnU-Net v2** and the **FeTS 2022** multi-institution glioma data with engineering the base tools lack:

1. a **site-held-out evaluation harness** that measures the accuracy gap at unseen hospitals;
2. **mitigations** (stronger intensity and bias-field augmentation, style augmentation, per-case standardization, instance-norm test-time adaptation), all compared under the same budget;
3. an **uncertainty monitor**: voxel entropy from seed replicates × flip TTA, a boundary-band case score, and a trust gate validated as a failure detector (AUROC, risk-coverage, ECE);
4. a **browser dashboard**: three linked views, a WebGL 2 volume renderer, overlays, a report panel with the flag, a review queue, a generalization explorer, a site risk report and a model card.

## Quickstart (clean clone, synthetic fixtures, no data needed)
```bash
python -m venv .venv && . .venv/bin/activate         # Windows: .venv\Scripts\activate
pip install -r requirements.lock --extra-index-url https://download.pytorch.org/whl/cpu
pip install -e . --no-deps
python scripts/tasks.py test                          # = make test
python scripts/synthetic_demo.py                      # SYNTHETIC explorer demo data
python -m playwright install chromium && python scripts/tasks.py test-ui
```

## Reproduce the laptop pilot (this machine)
```bash
python scripts/tasks.py data-report                       # Phase 0 (data situation A)
python scripts/tasks.py convert                           # Phase 1: canonical RAS
python scripts/tasks.py sitegroups                        # site groups and folds
python scripts/tasks.py nnunet-prep                       # nnU-Net raw + preprocessed dataset
python scripts/train_loso.py --methods baseline --groups mid --yes    # 10 epochs (configs/train.yaml)
python scripts/infer.py --methods baseline --groups mid --per-split 15 --rolling --stop-at 18:30
python scripts/run_experiments.py                         # E1-E6 -> results/
python scripts/build_docs.py && python scripts/build_report.py
python scripts/tasks.py app                               # http://127.0.0.1:8000
```
On Windows, launch long jobs as detached processes (e.g. PowerShell `Start-Process`) so they survive a closed terminal.

## Full protocol on a GPU machine
1. Obtain the **FeTS 2022 training data** (registration on Synapse) and the **partitioning CSV** (`Partition_ID, Subject_ID`).
2. Set `raw_root` and `institution_table` in `configs/data.yaml`.
3. `make data-report convert sitegroups` and commit `data/splits/` (rule 8: tau and the review-limit rule are already fixed in `configs/uncertainty.yaml`).
4. `make nnunet-prep ARGS=--plan`, then `python scripts/train_loso.py --dry-run` (prints the estimate), then `--yes`. Set `epochs: 100` and `plans` in `configs/train.yaml` for the full protocol.
5. `make infer ARGS="--methods baseline strong_aug style_aug standardize_pct tta_entropy"`, then `make eval`, `make docs`.

The GPU image is `docker/Dockerfile.train`. `docker/docker-compose.yml` runs the app and the MLflow UI.

## Where things live (never committed)
- `data/`: manifest, processed volumes, nnU-Net folders, fixtures, review database.
- `results/predictions/`, `results/cache/`: prediction records and caches. `mlruns/`: MLflow runs. `dist/`: the single-file demo.
- Checkpoints: `data/nnUNet_results/`.

## Privacy
No patient data is sent anywhere. The API makes no outbound calls and logs only route templates (no case ids, file names or query strings). Free-text NIfTI header fields are never copied. Files opened locally in the viewer stay in the browser. The FeTS data use agreement applies to any redistribution of scans, including the single-file demo.
